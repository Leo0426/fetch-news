# 0.7.13

## Changes

Remove the fixed aspect ratio and minimum height from reader covers. Images now determine the cover
height, capped at 240px, without top or bottom letterboxing. Images that exceed the cap crop to fill
the available width. The responsive card columns and smaller type remain as released in 0.7.12.

## Validation and deployment

- Build the JAR and amd64 image; run the source-size and reader-rendering checks.
- Inspect loaded images on desktop and mobile, plus list mode.
- Load `fetch-news:0.7.13-amd64` on NAS, stop the current container, and back up the data directory.
- Preserve the data mount, environment overrides, ports, logging, and restart policy.
- Retain the stopped 0.7.12 container for rollback. No database or configuration migration is required.
- Verify authenticated reader, admin, bookmarks, search, and briefing requests and the reader stylesheet
  checksum. The switch causes a brief interruption while containers are exchanged.

## Rollback

Run the protected `rollback.sh` written beside this release's NAS data archive as root. It stops and
removes the new container, restores the retained 0.7.12 container's name and restart policy, and starts it
against the existing data directory.
